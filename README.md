## Running Locally (Emulator)

1. Run Firestore emulator:
   - `firebase emulators:start`
2. In another terminal, run local web server:
   - `npm run dev`
3. Open:
   - `http://localhost:8888/?env=local`

### Optional local emulator URL params

- `?env=local` forces emulator mode
- `?emulatorHost=<ip-or-hostname>` sets emulator host
- `?emulatorPort=<port>` sets emulator port (default `8080`)
- Example for phone on same network:
  - `http://<your-lan-ip>:8888/?env=local&emulatorHost=<your-lan-ip>&emulatorPort=8080`

## Running in Production (Hosted Web)

1. Set environment variables (locally in `.env`, and in Netlify for production):
   - `FIREBASE_API_KEY`
   - `FIREBASE_AUTH_DOMAIN`
   - `FIREBASE_PROJECT_ID`
   - `FIREBASE_STORAGE_BUCKET`
   - `FIREBASE_MESSAGING_SENDER_ID`
   - `FIREBASE_APP_ID`
2. Generate client config file:
   - `npm run build:config`
   - this writes `js/firebase-config.js` from your environment values
   - `js/firebase-config.js` is gitignored to prevent accidental credential commits
3. Deploy to Netlify:
   - Connect repo in Netlify and deploy (publish dir is already configured as `.`)
   - Netlify will run `npm run build` first, which generates config from Netlify env vars
4. Open deployed site normally (no `env` query param needed)
   - Production mode is used automatically on non-localhost domains
   - You can force prod locally with `?env=prod`

### Netlify Environment Variables Setup

1. In Netlify, open:
   - Site settings -> Build & deploy -> Environment
2. Add all six `FIREBASE_*` variables listed above
3. Trigger redeploy

### GitHub Safety Notes

- Keep `.env` and `.env.*` out of git (already in `.gitignore`)
- Do not commit credentials in `firebase.js`
- `js/firebase-config.js` is generated by build tooling and intentionally not tracked

### Important security note

- Firebase `apiKey` in web apps is not a server secret; it is exposed to browsers by design.
- Real protection is in Firebase security rules and auth constraints.

## Setting up QR Code

1. Go to `https://www.qr-code-generator.com/` to create the code.
2. The link will be:
   - Local emulator mode: `<IP>:8888/?env=local&emulatorHost=<IP>`
   - Hosted production mode: your deployed URL

## Secret Shakespeare

Pressing `Shift` + `Enter` will toggle the ability to print out Shakespeare's Romeo and Juliet. There are no indicators on the UI, so be careful when you press it.  


## Setting Timer Values

Go to index.js and update the `timerValue` and `timerDisplayValue`. They should correlate with each other (01:00 = 60, 01:30 = 90).
